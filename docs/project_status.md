# 校园风险文本识别与可视化分析平台 项目总控文档

> 用途：作为本项目的长期实时更新文档。  
> 更新方式：每完成一个阶段、一个功能模块或一个关键决策，就在本文档中补充状态。  
> 当前更新时间：2026-03-28（晚间）

---

## 1. 总体规划

### 1.1 项目目标

在 1 个月内完成一个面向校园场景的风险文本识别与可视化 Web Demo，支持：

- 单条文本分析
- 批量文本分析
- 风险分类与风险分级
- 关键词、规则说明、大模型解释
- 大屏可视化展示
- 少量真实公开数据接入演示

### 1.2 建设原则

- 先跑通完整闭环，再逐步增强效果
- 先规则可用，再叠加小模型和大模型
- 先确保单人可控开发，再考虑扩展性
- 先做适合答辩展示的产品形态，再补深层能力

### 1.3 核心闭环

`输入文本 -> 风险识别 -> 风险分级 -> 解释说明 -> 可视化展示`

### 1.4 总体阶段划分

#### 第一阶段：项目底盘搭建

- 建立前后端目录结构
- 建立基础文档体系
- 建立样例数据目录
- 建立基础接口骨架

#### 第二阶段：后端分析链路

- 实现规则引擎
- 实现单条分析接口
- 实现批量分析接口
- 输出统一结果结构和统计汇总结构

#### 第三阶段：前端驾驶舱骨架

- 建立 Vue 大屏页面
- 建立状态管理、路由、接口层
- 接入图表、表格、分析面板
- 先支持演示数据回退，再联真实接口

#### 第四阶段：核心业务功能补全

- 批量导入文本文件
- 高风险文本详情弹窗或抽屉
- 搜索与筛选
- 词云和更多统计模块

#### 第五阶段：演示能力增强

- 接入少量真实公开数据
- 补充默认演示样本
- 优化页面视觉观感
- 整理答辩演示路径

#### 第六阶段：模型增强

- 外置规则词表
- 融合小模型分类能力
- 接入本地大模型解释层
- 优化风险评分与解释逻辑

### 1.5 当前推荐开发顺序

1. 后端规则引擎与批量分析继续完善
2. 前端批量导入与详情交互落地
3. 前后端联调形成可演示闭环
4. 增加真实数据接入入口
5. 最后再做模型增强和展示打磨
