# 校园风险文本识别与可视化分析平台 项目总控文档

> 用途：记录项目总体规划、当前进度、最新数据接入情况与下一步安排  
> 最近更新：2026-03-29

## 1. 总体规划

### 1.1 项目目标

在 1 个月内完成一个面向校园管理场景的 Web Demo，服务对象主要是学校老师、辅导员和行政人员。系统需要支持：

- 单条文本分析
- 批量文本分析
- 风险分类与等级判断
- 规则依据与模型解释展示
- 大屏可视化展示
- 少量真实公开数据接入

### 1.2 建设思路

- 先跑通完整闭环，再逐步增强模型能力
- 先让规则层稳定可解释，再叠加小模型和大模型
- 先保证答辩可演示，再追求更复杂的训练与优化
- 所有数据和文案优先贴近校园教师/行政使用场景

### 1.3 阶段路线

1. 项目骨架搭建
2. 后端规则引擎与分析接口
3. 前端驾驶舱与导入能力
4. 公开数据接入与联调
5. 本地 Llama 基础解释接入
6. 规则细化、数据投喂与答辩包装

### 2.4 当前重点

- 用校园场景语料继续检验规则稳定性
- 收缩“学校”这类高频通用词带来的舆情误判
- 继续优化 Llama 的解释提示词与输出风格
- 为后续更强模型或训练型分类器预留接入口
- 让整体判断更偏通用情感分析，再按校园管理场景做风险偏置

### 2.5 下一步

1. 细化规则词表，尤其是舆情风险触发条件
2. 将“学校”从单独触发词改为组合触发或上下文触发
3. 利用 `educator_interviews_rule_hit_review.csv` 做误判复核
4. 继续准备更贴近校园管理场景的人工样本
5. 在 `.env` 中填入实际大模型服务地址并开始联调强模型研判
6. 视需要补充更多模型档案，例如本地 vLLM、LM Studio 或自建兼容服务

### 2.6 风险与注意事项

- 当前规则层仍偏第一版，存在明显的领域误判
- 教师访谈语料验证后发现：仅凭“学校”一词会产生较多舆情风险误伤
- 本地 `Llama-3.2-3B` 适合做基础解释，不适合承担复杂分类主判定
- 前端构建可用，但仍有打包体积偏大的警告
